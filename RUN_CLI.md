# 🚀 Run Yasser Gombra's Interactive TUI CV

Experience a fully interactive, AI-powered Terminal User Interface (TUI) CV directly from your command line. No installation required!

---

## 💻 Quick Start

Simply run the following command in your terminal:

```bash
npx yassergombra
```

## ✨ Features

- **🤖 AI Chat Integration**: Chat with Yasser's personal AI agent in real-time. Ask questions like:
  - *"What is Yasser's tech stack?"*
  - *"Is Yasser looking for a job?"*
  - *"Tell me about the Specter project."*
- **📂 Interactive Navigation**: Switch between views instantly using hotkeys:
  - Press `P` for **Projects**
  - Press `S` for **Skills**
  - Press `E` for **Experience**
  - Press `C` for **Contact Info**
  - Press `H` for **Help**
- **⚡ Zero Setup**: Runs instantly via `npx` using Node.js.
- **📱 Responsive Layout**: Automatically resizes components to fit your terminal window perfectly.

---

## 🛠️ Prerequisites

To run this CLI app, you only need:
* **Node.js** (v18 or higher)
* An active internet connection (to connect to the AI assistant)

---

> [!TIP]
> **Pro Tip:** Make sure your terminal window is at least **80 columns wide** and **24 lines high** for the best layout and visual experience!
