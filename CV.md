## 🚀 Projects

### **Specter** | [GitHub Repository](https://github.com/YasserYG8/Specter)
Zero-configuration developer CLI in Go that attaches to any running server process by port or PID and streams live stdout and stderr to the terminal. Features procfs inspection, automatic TCP port resolution, line reassembly, and JSON log formatting, with zero external runtime dependencies.
* **Tech Stack:** Go, Linux /proc, Syscalls, Concurrency, CLI / TUI, DevOps

### **VoxArena ML**
Deterministic acoustic signal processing engine for vocal imitation party games. Scores mimicry against sound effects using speaker-normalized pYIN pitch tracking, constrained Dynamic Time Warping, spectral flux onset detection, and MFCCs with CMS for sub-50ms CPU scoring. Includes a full FastAPI and MongoDB game architecture.
* **Tech Stack:** Python, FastAPI, Librosa, FastDTW, SciPy, MongoDB, Signal Processing

### **Modlane** | [GitHub Repository](https://github.com/YasserYG8/modlane)
Adaptive AI model router and low-latency API proxy for coding agents. Sends routine actions (file reading, AST search, git commits) to fast, inexpensive models and keeps frontier models for complex refactoring, cutting agent costs by up to 70%.
* **Tech Stack:** TypeScript, Node.js, OpenAI & Anthropic APIs, Streaming SSE, AI Agents, Gateway

### **Tajweed AI** | [GitHub Repository](https://github.com/YasserYG8/Tajweed-AI)
Machine learning dataset engine and acoustic alignment pipeline for Quranic recitation. Combines ASR forced alignment (WhisperX and MFA) with deterministic DSP rules to evaluate phoneme boundaries, Madd duration, Ghunnah resonance, and Qalqalah transients.
* **Tech Stack:** Python, WhisperX, MFA, PyTorch, DSP, Levenshtein Diff

### **ImanHub** | [GitHub Repository](https://github.com/YasserYG8/ImanHub)
Cross-platform Islamic companion mobile app. Features a 604-page dual-mode Quran reader with audio sync and tafsir, offline astronomical prayer calculation, a magnetometer-driven Qibla compass, a customizable Athkar counter, and localized push notifications.
* **Tech Stack:** React Native, Expo, TypeScript, Expo Router, AsyncStorage, Sensors & Geolocation, Reanimated
